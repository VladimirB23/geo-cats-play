# Credits

Every external asset and data source used by the game. Nothing in this repository comes from the reference game.

## Map

- **Natural Earth** (1:50m Admin 0 countries) — public domain. <https://www.naturalearthdata.com/>
- Packaged as **world-atlas 2.0.2** by Mike Bostock — ISC licence. <https://github.com/topojson/world-atlas>
- **Natural Earth** lakes (1:50m, and Loch Ness from 1:10m) and river centre lines (1:50m, the larger rivers) —
  public domain. Converted to TopoJSON by `scripts/build-water.ts` with **topojson-server 3.0.1** (ISC, dev only).
  <https://github.com/nvkelso/natural-earth-vector>

## Code

- **three.js 0.187.0** — MIT. The 3D cat (`src/ui/cat3d/scene.ts`), built in code from simple shapes; no model files.

## Music

All music is synthesised in code (`src/platform/sound.ts`); there are no audio files. The themes in
`src/platform/tunes.ts` are in the public domain: «Ode to Joy» (L. van Beethoven, Symphony No. 9, 1824),
«Sakura Sakura» (Japanese folk song, Edo period), «Oh! Susanna» (S. Foster, 1848), «La Cucaracha» (Mexican
folk song). The motifs for South America, Africa and Oceania are original to the game.

## Data

- **Wikidata** — ISO codes of the 195 states, capitals and their coordinates, links to Russian Wikipedia articles; CC0.
  Fetched by `scripts/build-data.ts`. <https://www.wikidata.org/>
- **World Bank Open Data** — population, surface area and GDP (current US$) of the states, the latest year available
  for each; CC BY 4.0. Indicators SP.POP.TOTL, AG.SRF.TOTL.K2, NY.GDP.MKTP.CD. <https://data.worldbank.org/>
- **Wikidata** again for cities and sights: coordinates, city population and the name of the photo; CC0.
  Fetched by `scripts/build-places.ts` from the lists in `content/cities.json` and `content/sights.json`.
- **Unicode CLDR** (through the Node.js `Intl.DisplayNames` API) — Russian country names; Unicode License.
- **Russian Wikipedia** — linked as the source in item cards (links only, no copied text); CC BY-SA 4.0.
- Card texts are original and written for this project.
- **Wikipedia** (Russian and English) — linked as the sources of the cards in the collection of cats; every fact of
  a card was checked against the English article, the texts themselves are original. CC BY-SA 4.0.

## Flags

- **flag-icons 7.6.0** by Panayiotis Lipiridis — MIT licence. SVG flags, 4:3. <https://github.com/lipis/flag-icons>

## Sound

- Effects and music are synthesised in the browser with the Web Audio API (`src/platform/sound.ts`).
  The game ships no audio files.

## Fonts

- **Onest** (variable) via `@fontsource-variable/onest` 5.3.1 — SIL Open Font License 1.1.
- **Unbounded** (variable) via `@fontsource-variable/unbounded` 5.3.0 — SIL Open Font License 1.1.

## Artwork

- The cat, the paw print and the icons are original SVG drawings made for this project.

## Libraries

Runtime: React, d3-geo, d3-zoom, d3-selection, d3-transition (ISC), topojson-client (ISC), topojson-simplify (ISC), zustand, zod, idb-keyval (Apache-2.0).
All MIT unless noted. Full list with versions: `package.json`.

The service worker that keeps the game available offline (`sw.js`, `workbox-*.js` in the build) is generated by
**vite-plugin-pwa 2.0.0** (MIT) from Google's **Workbox 7.4** (MIT). The app icons in `public/icons/` are rendered
from the project's own paw drawing by `scripts/build-icons.ts`.
